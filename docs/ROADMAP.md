# 🗺️ Roadmap de Implementação dos Design Patterns (GoF)

Este documento define a ordem recomendada para estudar e implementar todos os 23 padrões GoF utilizando TypeScript, dentro do monorepo **design-patterns-ts**.

O roadmap foi organizado em semanas, seguindo progressão de complexidade e relação entre padrões.

---

# 📅 Semana 1 — Fundamentos Essenciais

### 🎯 Objetivo: criar base sólida e pegar ritmo

1. **Strategy**
2. **Observer**
3. **Singleton**
4. **Factory Method**

---

# 📅 Semana 2 — Padrões Criacionais (Parte 1)

### Objetivo: dominar abstrações de criação de objetos

5. **Abstract Factory**
6. **Builder**
7. **Prototype**

---

# 📅 Semana 3 — Estruturais (Parte 1)

### Objetivo: organizar relacionamentos entre classes

8. **Adapter**
9. **Facade**
10. **Decorator**
11. **Composite**

---

# 📅 Semana 4 — Estruturais (Parte 2 — Avançados)

12. **Proxy**
13. **Bridge**
14. **Flyweight**

---

# 📅 Semana 5 — Comportamentais (Parte 1)

### Objetivo: lógica, fluxo e controle de comportamento

15. **Command**
16. **State**
17. **Template Method**
18. **Chain of Responsibility**

---

# 📅 Semana 6 — Comportamentais (Parte 2)

19. **Mediator**
20. **Iterator**
21. **Memento**

---

# 📅 Semana 7 — Comportamentais Avançados

22. **Visitor**
23. **Interpreter**

---

# 🧠 Estrutura recomendada para cada padrão

Para cada padrão:

1. Criar pasta em `patterns/<padrão>`
2. Criar `README.md`
3. Implementar interfaces e classes
4. Criar exemplo em `client/`
5. Criar testes em `test/`
6. Escrever reflexão final

---

# 🚀 Benefícios desse Roadmap

- Progressão suave e consistente
- Abordagem prática e teórica
- Construção de portfólio
- Aprendizado sólido para entrevistas, arquitetura e código limpo
